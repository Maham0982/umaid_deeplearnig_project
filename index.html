01 — MODEL ARCHITECTURE

Residual learning
for visual patterns.

ResNet stands for Residual Network. It is a convolutional neural network architecture designed to learn useful visual features through layers of processing. Residual or “skip” connections let information travel across blocks, helping deeper networks learn effectively.

In image classification, those learned features can represent edges, textures, shapes and more complex visual patterns. The final model output is used to select the class with the strongest predicted score.
